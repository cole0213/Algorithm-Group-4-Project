01 — Background

왜 만들었나요?

면접 서류심사 시 지원자마다 제각각 형식으로 제출되는 포트폴리오를 일일이 열어보는 것은
시간도 오래 걸리고 기준 없이 주관적으로 흐르기 쉽습니다.
모든 형식을 통일된 서식으로 변환하고, 알고리즘으로 객관적 비교를 제공합니다.
React + Vite Python + FastAPI Upstage Solar LLM pdfplumber session.json localStorage
02 — Core Algorithms

8가지 알고리즘

#01
Solar LLM
비정형 포트폴리오를 구조화된 JSON으로 자동 파싱·정형화
#02
Hash Table
필요 스펙 O(1) 매칭·하이라이트. 빠른 스킬 보유 확인
#03
Edit Distance
DP 기반 오타·약어 허용 매칭. 기술명 표기 차이 흡수
#04
LCS (DP)
공통 부분 수열로 스펙 매칭 점수 0~100% 산출
#05
Sort
매칭률·경력·이름 기준 지원자 순위 정렬
#06
BST
전체(cross) / 패널 내부(intra) 두 모드 키워드 검색
#07
Alias Map
JS→JavaScript, py→Python 동의어·오타 통합 검색
#08
Rabin-Karp
슬라이딩 윈도우 + LCS로 포트폴리오 간 유사 문장 검출

05 — What's New in v2

새로 추가된 부가 기능

prototype-v2
기존 기능 위에 쌓인 5가지 개선
심사 편의성 · UX 완성도 · LLM 활용 확장
01

블라인드 심사 모드

지원자 이름을 가려 내용만으로 평가. 무의식적 편향 없이 공정한 심사 가능

02

지원자별 메모 & 마킹

패널 하단 코멘트 입력 + 통과 / 보류 / 탈락 마킹 드롭다운. 로컬 자동 저장

03

매칭 점수 가중치 조절

스킬 비율 · 경력 연수 · 프로젝트 수를 슬라이더로 직접 조정해 커스텀 점수 산출

04

업로드 단계별 진행 표시

파일 읽기 → LLM 파싱 중 → 저장 중 → 완료, 4단계 실시간 진행 안내

05

공고 텍스트 → 스펙 자동 추출

채용 공고 붙여넣기 → Solar LLM이 필요 스펙 파싱 → 분석 조건 자동 채움
