## 1. 포트폴리오 관리

### 1-1. 포트폴리오 추가
- **지원 형식**: `.pdf`, `.md`, `.txt` 파일 업로드, 또는 텍스트 직접 붙여넣기
- **파일 업로드**: 드래그앤드롭 또는 클릭 선택
- **직군 선택**: 일반 / 프론트엔드 / 백엔드 / 데이터AI — 직군별로 Solar LLM 프롬프트 분기
- **지원자 이름**: 선택 입력 (미입력 시 파일명 기반 자동 설정)
- **Solar LLM 파싱**: 업로드된 포트폴리오를 Solar AI가 자동으로 정형화
- **폴백 처리**: Solar 파싱 실패 시 기본 파서(basic_parser)로 자동 전환
- **업로드 진행 표시**: 파일 읽기 → LLM 파싱 중 → 저장 중 → 완료, 4단계 진행 상황 표시
- **파싱 결과 디버그**: 소요 시간, 토큰 수, 절단 여부 확인 가능
- **절단 경고**: 원문 8,000자 초과 시 패널 상단에 ⚠ 경고 배너 표시
- **중복 감지**: 동일 파일명 또는 이름 재업로드 시 경고

### 1-2. 포트폴리오 재파싱
- 이미 추가된 포트폴리오를 파일 재업로드 없이 Solar LLM으로 재분석
- 패널 내 재분석 버튼 제공

### 1-3. 포트폴리오 삭제
- 사이드바 항목의 ✕ 버튼으로 삭제
- **삭제 되돌리기 (Undo)**: 삭제 직후 5초간 취소 토스트 표시, 버튼 클릭 시 복구

### 1-4. 이름 변경
- 사이드바 항목 더블클릭 → 이름 인라인 편집 (Enter 저장, Esc 취소)

## 2. 스펙 매칭 및 정렬

### 2-1. 스펙 매칭 분석
- 상단 바 필요 스펙 입력창에 쉼표 구분으로 스펙 입력 후 `분석` 클릭
- **알고리즘**: 해시 테이블 O(1) 스킬 매칭 + LCS DP 매칭 점수 산출
- **결과**: 지원자별 매칭률(0~100%) 계산, 사이드바 배지 및 패널 하이라이트 업데이트
- **분석 완료 배너**: "총 N명 중 M명이 70% 이상 매칭" 요약 배너 표시 (✕로 닫기 가능)

### 2-2. 매칭 점수 가중치 커스텀
- 스킬 비율 / 경력 연수 비율 / 프로젝트 수 비율을 슬라이더로 조정
- 설정 드로어에서 수치 변경 시 백엔드 가중 합산 연동

### 2-3. 정렬
- 상단 바 정렬 드롭다운: **매칭률 높은 순** / **경력 많은 순** / **이름 순**
- **알고리즘**: 커스텀 정렬 (sort.py)

### 2-4. 매칭률 배지
- 사이드바 각 항목에 매칭률 표시
- 70% 이상: 초록 / 40~69%: 주황 / 39% 이하: 빨강 / 미분석(0%): 회색

## 3. 검색

### 3-1. 전역 키워드 검색 (cross mode)
- 상단 검색창에 입력 (300ms debounce)
- **별칭 통합 검색**: `JS` → `JavaScript`, `py` → `Python` 등 동의어 자동 통합 (별칭 해시맵)
- **오타 허용**: Edit Distance로 유사 키워드 매칭
- **BST 검색**: 전체 포트폴리오를 대상으로 BST 인덱스 기반 탐색
- 검색 결과 없는 지원자: 사이드바에서 흐리게(opacity 0.4) 처리

### 3-2. 패널 내 검색 (intra mode)
- 각 포트폴리오 패널 상단 검색 바에 개별 입력
- 해당 패널 텍스트 내에서만 실시간 하이라이트
- 결과 건수 표시 + ▲▼ 버튼으로 이전/다음 결과 이동
- 첫 번째 결과로 자동 스크롤

### 3-3. 검색 기록
- 최근 검색어 최대 8개 localStorage 저장
- 검색창 포커스 시 드롭다운으로 재사용 가능

### 3-4. 사이드바 이름 필터
- 사이드바 상단 이름 검색 입력창 (전역 검색과 별도)
- ✕ 버튼으로 즉시 초기화

## 4. 유사 문장 검출

### 4-1. 유사 문장 자동 검출
- **알고리즘**: Rabin-Karp 슬라이딩 윈도우로 후보 탐색 + LCS로 유사도 측정
- 임계값 초과 시 동일 그룹 색상 부여, 패널에 색상 하이라이트 표시
- 감지 범위 선택: **전체 포트폴리오** 또는 **현재 열린 패널만**

### 4-2. 유사 문장 표시 제어
- 설정 드로어에서 표시/숨기기 토글
- 숨기기 ON: 유사 문장 구간 opacity 0.3으로 흐리게 처리 (삭제 아님)
- 패널별 독립 숨기기/보이기 버튼 제공

### 4-3. Diff 비교 모달
- 패널이 2개 열린 상태에서 "⇄ 비교" 버튼 클릭
- 두 지원자의 유사 문장 구간을 나란히 표시
- Solar AI 기반 diff와 로컬 알고리즘 diff 배지 구분

### 4-4. 그룹 색상 커스텀
- 6개 그룹 × 9가지 색상 프리셋 선택 가능
- `↻ 유사 문장 재검출` 버튼

## 5. 심사 보조

### 5-1. 지원자 마킹
- 각 사이드바 항목에서 **통과 / 보류 / 탈락** 상태 마킹
- 마킹 드롭다운으로 선택, localStorage에 영구 저장
- 색상으로 상태 즉시 구분 (초록/노랑/빨강)

### 5-2. 북마크 (즐겨찾기)
- ☆/★ 버튼으로 즐겨찾기 지정
- 북마크된 항목 사이드바 상단 고정
- localStorage 저장

### 5-3. 지원자별 메모
- 포트폴리오 패널 하단에 textarea 제공
- 심사 코멘트 자유 입력, localStorage에 자동 저장

### 5-4. 블라인드 심사 모드
- 설정 드로어에서 토글
- ON 시 사이드바 및 패널에서 지원자 이름 가림
- 무의식적 편향 없이 내용 기반 심사 가능

### 5-5. 추가 일시 기록
- 포트폴리오 추가 시 `_added_at` 타임스탬프 자동 저장
- 패널 기본 정보 섹션에 표시

## 6. 뷰 및 UI

### 6-1. 포트폴리오 패널
- 우측 영역에 최대 4개 수평 나열, flex: 1 동적 분할
- **섹션 아코디언**: 기본정보 / 기술스택 / 자기소개 / 프로젝트 / 수상활동 개별 접기/펼치기
- **스킬 태그**: 기본 5개 표시, "더보기" 버튼으로 전체 펼치기
- **링크 버튼 바**: GitHub, Notion, LinkedIn 등 포트폴리오 내 주요 URL을 패널 상단에 버튼으로 표시 (플랫폼별 이모지 아이콘)
- **Solar 뱃지**: Solar LLM으로 파싱된 경우 "Solar" 표시 + hover 툴팁
- **코드블럭 렌더링**: 포트폴리오 내 코드 블럭을 `<pre>` 형식으로 렌더링
- **마크다운 볼드·링크** 렌더링

### 6-2. 원본 보기
- 패널 하단 "원본 보기 →" 버튼 클릭
- 정형화 전 원본 텍스트를 오버레이 모달로 표시

### 6-3. 패널 전체화면 모드
- ⊞/⊡ 버튼으로 단일 패널을 화면 전체로 확대
- Esc 키로 해제

### 6-4. 동기화 스크롤
- 패널 영역 우상단 토글로 ON/OFF
- ON 시 한 패널 스크롤 → 나머지 패널 비율 기반 동기 이동

### 6-5. 스킬 매트릭스
- 상단 바 ⊞ 버튼 클릭
- 전체 지원자 × 전체 스킬 격자 테이블 표시
- 스킬 보유 여부 한눈에 비교, 빈도순 정렬

### 6-6. 다크 모드
- 설정 드로어에서 토글
- `body.dark` 클래스 + CSS 변수 오버라이드

### 6-7. 필터 패널 (사이드바)
- 사이드바 내 필터 패널 펼치기
- **경력 최소 연수** / **스킬 포함** / **이름 포함** / **추가 날짜 범위** 조건 필터

## 7. 데이터 관리

### 7-1. 서버 영속성
- 포트폴리오 추가·삭제·변경 시 `backend/session.json` 자동 저장
- 서버 재시작 후에도 데이터 유지

### 7-2. 브라우저 캐시
- `portfolio-reviewer-cache` 키로 localStorage 저장
- 페이지 로드 즉시 캐시 데이터 표시 → 백엔드 응답 후 최신 데이터로 갱신
- 백엔드 오프라인 상태에서도 캐시 데이터 열람 가능

### 7-3. 내보내기 (Export)
- 상단 바 ↓ 버튼 클릭
- 현재 세션의 전체 포트폴리오를 JSON 파일로 다운로드

### 7-4. 불러오기 (Import)
- 상단 바 ↑ 버튼으로 JSON 파일 선택
- **덮어쓰기** 또는 **병합** 모드 선택 (confirm 다이얼로그)
- 중복 ID 자동 처리

### 7-5. 공고 텍스트 → 스펙 자동 추출
- 상단 바 공고 입력 팝업에 채용 공고 텍스트 붙여넣기
- Solar LLM이 `required` / `preferred` 스펙 JSON으로 자동 파싱
- 분석 입력창에 자동 채움

## 8. 사용자 편의 기능

### 8-1. 토스트 알림
- 포트폴리오 추가 / 삭제 / 임포트 / 재분석 완료 시 우측 하단 스낵바 표시

### 8-2. 스켈레톤 UI
- 분석 중 shimmer 카드 3개 표시, 완료 후 목록으로 교체

### 8-3. 빈 상태 안내 화면
- 포트폴리오 0건일 때 Sidebar와 PortfolioArea에 안내 문구 + 추가 버튼 표시

### 8-4. 패널 스크롤 위치 복원
- 패널 닫고 다시 열 때 이전 스크롤 위치로 자동 복원

### 8-5. 키보드 단축키
- `Esc`: 모달 / 드로어 / 패널 닫기

### 8-6. 이름 툴팁
- 사이드바에서 이름이 말줄임표로 잘릴 때 hover 시 전체 이름 표시

## 9. 설정

설정 드로어 (`⚙` 버튼)에서 제어 가능한 항목:

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 스킬 하이라이트 | ON | 분석 후 매칭 스펙 배지 강조 표시 |
| 유사 문장 표시 | ON | 포트폴리오 간 유사 구간 색상 하이라이트 |
| 유사 문장 숨기기 | OFF | 유사 구간 opacity 0.3으로 흐리게 처리 |
| 동기화 스크롤 | OFF | 패널 간 스크롤 비율 동기화 |
| 원본 링크 버튼 | ON | 패널 상단 링크 버튼 바 표시 |
| 별칭 통합 검색 | ON | py·파이선 등 동의어·오타 통합 검색 |
| 블라인드 심사 | OFF | 지원자 이름 가리기 |
| 다크 모드 | OFF | 어두운 테마 |
| 매칭 가중치 슬라이더 | 균등 | 스킬/경력/프로젝트 비율 조정 |
| 유사 문장 감지 범위 | 전체 | 전체 포트폴리오 또는 열린 패널만 |
| 그룹 색상 커스텀 | 프리셋 | 유사 문장 그룹별 색상 변경 |
