### 검색 기능 개선 사항

- 숫자 검색이 현재 작동하지 않음
- 왼쪽 검색창은 "py"나 "python" 등 한글/영어 모두 감지되지만, 오른쪽 필요 스펙 퍼센트 검색창은 한글 입력 시 작동하지 않음
- 검색창 두 개가 연달아 있어 구분이 어려움 - 각 검색창의 용도를 명시하는 라벨 추가 필요 (예: "일치율 검색", "지원자 검색" 등)
- 지원자 이름 검색 시 띄어쓰기 감지 문제 발견 - 본문 내용만 검색하는 것과 지원자 목록 검색을 분리하는 방안 고려
- 검색 시 두 영역(지원자 목록 + 포트폴리오 내용)이 동시에 필터링되어 혼란스러움

### 명명 규칙 및 일관성

- 지원자 목록의 제목을 한글과 영어 이름으로 통일 필요
- 지원자 번호/이름을 사용자가 직접 지정할 수 있는 기능 추가 (우클릭 → 이름 변경하기)
- 동명이인 처리: 중복된 이름 추가 시 "동명이인입니다만 추가하시겠습니까?" 경고 표시

### 유사도 및 중복 감지 기능

- 유사 문장 감지 기능은 작동하나, 자동으로 실행되지 않고 버튼을 눌러야 함 - 자동 감지로 변경 필요
- 비슷한 포트폴리오가 있을 경우 흐리게 처리 또는 빨간색 표시 기능
- 색깔 구분: 회색은 동일인물 표시, 다른 색상은 유사 문장 표시
- 파일 중복 감지 기능 추가 필요

### UI/UX 개선

- 첫 페이지에 시작 버튼이나 프로젝트 리스트 같은 명확한 진입점 필요 여부 논의 - 현재 페이지의 직관성을 높이는 것으로 결론
- 설정 기능이 직관적으로 보이지 않음 - 개선 필요
- 포트폴리오 추가 시 "포지션 유형" 필드는 불필요함
- "흐리게" 버튼과 "색깔로 표시" 버튼의 구분이 명확하지 않음 - 표현 방식 개선 필요
- 불러오기 기능이 추가만 되고 덮어쓰기가 되지 않음 - 기존 작업 내용과 동일한 파일 감지 시 경고 후 덮어쓰기 옵션 제공

### 기술적 문제

- 마크다운(볼드 처리 등)이 인식되지 않음
- PDF 파일 지원: 현재 MD 파일만 지원하나 PDF도 텍스트 추출하여 AI 처리 가능한지 테스트 필요
- PDF 파일 업로드 테스트 결과 잘 작동함 확인

### 비교 기능 개선

- 현재 최대 4명까지만 비교 가능 - 더 많은 인원 비교 가능하도록 확장 고려
- 필요 스펙 충족률(66%, 67% 등) 표시가 지원자끼리 비교하는 것인지, 요구 스펙을 얼마나 충족하는지 명확히 해야 함

### 링크 처리 기능

- 포트폴리오에 GitHub 등의 링크가 있으면 자동으로 버튼 생성하여 이동할 수 있게 구현

### 데이터 형식

- 포트폴리오 형식을 MD와 PDF로 지정
- 현재 임시 포트폴리오는 모두 MD 파일로 저장됨
- 포트폴리오 포맷 방식을 지정된 키로 고정
