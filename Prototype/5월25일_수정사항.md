## 4. 유사 문장 팔레트 색상 통일 오류 수정

**증상**: 컬러풀 팔레트 사용 시 그룹 6 이상에서 색상이 `undefined`가 되어 표시 불량  
**원인**: `groupColors[span.group]` — 배열 범위 초과  
**수정** (`api.js`): 모듈로 연산으로 교체

```js
// 수정 전
const color = groupColors?.[span.group];

// 수정 후
const color = groupColors?.length ? groupColors[span.group % groupColors.length] : span.color;
```

## 5. 유사 문장 감지·하이라이트 오류 수정 (4단계)

### 5-1. 윈도우 병합 누락

**원인**: 연속된 5-단어 윈도우가 각각 별개 span으로 반환되어 일부만 하이라이트  
**수정** (`rabin_karp.py`): `_merge_ranges()` 추가 — 인접·겹치는 윈도우를 하나의 연속 구간으로 병합

### 5-2. 소문자 변환 텍스트로 span 생성 문제

**원인**: 매칭에 사용한 소문자 단어 리스트로 span 텍스트를 재조합 → 원문 대소문자·구두점 손실로 `indexOf` 실패  
**수정** (`rabin_karp.py`): `_tokenize()` 도입 — `(정제어, char_시작, char_끝)` 튜플로 원문 문자 위치 추적

### 5-3. intro 필드 하이라이트 파이프라인 누락

**원인**: `PortfolioPanel.jsx`의 `introLines`가 `renderMarkdown(raw)`를 바로 호출해 `applySimilarHighlight` 미적용  
**수정** (`PortfolioPanel.jsx`): 유사 문장 하이라이트를 마크다운 렌더링보다 먼저 적용

```js
const introLines = (() => {
  const raw = a.intro ?? '';
  const withSimilar = applySimilarHighlight(raw, similarSpans, settings.similar, effectiveHide);
  if (typeof withSimilar !== 'string') return applyQueryHighlights(withSimilar, searchQuery, intraActive);
  return renderMarkdown(withSimilar);
})();
```

### 5-4. 섹션 경계를 넘는 span 생성 문제 (**근본 원인**)

**원인**: 내용이 유사한 두 포트폴리오를 비교할 때 `_merge_ranges`가 intro + 모든 프로젝트 desc를 포괄하는 단일 대형 span 생성 → 프론트엔드에서 `a.intro.indexOf(span_text)` 실패  
**수정** (`rabin_karp.py`):

- `_build_sections(portfolio)` 추가: 섹션별(intro, 각 프로젝트 desc) 토큰·단어 인덱스 경계 계산
- `_section_spans(merged, sections, ...)` 추가: 병합 범위를 섹션 경계에서 잘라 각 섹션 원문 기준 span 텍스트 생성
- `detect_similar()` 간소화: 위 두 헬퍼 사용

**결과**: 하나의 병합 범위가 여러 섹션에 걸쳐 있어도 intro span은 `a.intro`에서, desc span은 `p.desc`에서 각각 독립적으로 추출되어 프론트엔드 `indexOf` 탐색 성공
