# 제일 중요한 기능인 포트폴리오 뷰가 읽기 어려움.
지금 상태는 단순 요약만 진행되어버린 상태입니다. 문장과 줄이 문맥에 구분되지않고 줄넘김 없이 연속적으로 표기되며, 단락 구분 또한 되어 있지 않습니다. 마크다운이 제대로 지원되지도 않고 있습니다.

## 섹션 구분 방식의 통일성을 따르되, 섹션은 채용 설정에서 설정 가능토록 함.

## 마크다운 문법을 확실히 지원하도록 신용되는 외부 라이브러리를 사용합니다.

## 타임라인을 표기하는 섹션을 추가합니다.
포트폴리오에 명시되어 있거나 확인 가능한 내용을 가져옵니다. 이후 타임라인으로써 볼 수 있도록 새로운 UI를 구성하여 포트폴리오 뷰어의 섹션중 하나로 놓습니다.
가로 타임라인 방식으로 합니다.

# 채용 설정을 통합적으로 관리할 설정 페이지가 필요합니다.
현재는 필요스펙 텍스트 인풋란에 버튼을 두어 AI 자동 설정을 가능토록 했지만, 따로 제작해야겠습니다. 페이지 또는 큰 모달을 띄워 설정이 가능하도록 되어야 할 것 같습니다.

# 기술 스택이 과도하게 많고, ai 환각이 가미되었습니다.
포트폴리오 내부의 기술스택이 아닌 스펙이 기술 스택에 표기되어있습니다. 기술 스텍이 너무 많기도 합니다.
기술 스텍이 포트폴리오의 판단에 중요히 작용되므로 환각에 주의하고, 과도하지 않고 기본적인 포트폴리오의 기술 스택 작성방식을 숙지하고, 분석하여 로드합니다.
