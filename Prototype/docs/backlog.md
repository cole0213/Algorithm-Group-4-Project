# 백로그 — 미구현 아이디어

구현이 완료된 항목은 제거하고 아직 구현되지 않은 기능과 개선 아이디어만 정리한다.

---

## 기능 확장

| 항목 | 설명 |
|------|------|
| 포트폴리오 그룹핑 | 직군별·전형별 폴더 분류 |
| 분석 결과 PDF 내보내기 | 심사 결과표 형식으로 다운로드 |
| 분석 결과 엑셀(.xlsx) 내보내기 | 스킬 매트릭스 + 매칭률 포함 |
| 종합 보고서 내보내기 | 심사 마킹·메모 포함 |
| 공유 링크 생성 | 읽기 전용 뷰 URL (현재는 JSON 파일 전달만 가능) |
| 특정 스펙 보유자 하이라이트 규칙 저장 | 매번 재입력 없이 규칙 유지 |
| 시맨틱 검색 | 벡터 임베딩 기반 의미 유사 검색 (현재는 BST 키워드 방식만) |
| 다중 사용자 지원 + 로그인 | 팀 단위 사용, 현재는 로컬 단일 사용자 |
| 면접 질문 자동 생성 | 포트폴리오 기반 Solar LLM 질문 초안 제안 |
| 기술 트렌드 대시보드 | 지원자 전체 스킬 분포 시각화 |
| 채용 시즌 비교 | 이번 기수 vs 지난 기수 스킬 분포 추이 |

---

## UI / UX 개선

| 항목 | 설명 |
|------|------|
| 필요 스펙 태그 pill UI | 쉼표 텍스트 입력 → Enter로 태그 생성, 개별 삭제 |
| 패널 드래그앤드롭 재배치 | 현재는 클릭 순서로만 결정 |
| 패널 너비 드래그 리사이즈 | 현재 `flex: 1` 균등 분할 고정 |
| 패널 핀 고정 버튼 | 고정된 패널은 사이드바 클릭으로 닫히지 않음 |
| 버튼·기능 툴팁 도움말 | hover 시 기능 설명 표시 |

## 내부 구조 개선

| 항목 | 설명 | 우선순위 |
|------|------|---------|
| Solar API 비동기 큐 | 폴더 업로드 시 LLM 호출을 큐에 쌓아 순차 처리 + 진행 상태 표시 (현재는 요청당 블로킹) | 중 |
| session.json 증분 저장 | 현재 추가/삭제마다 파일 전체 재작성 → 대용량 시 SQLite로 교체 고려 | 하 |
| LLM 응답 검증 레이어 | 파싱 결과의 hallucination 점수를 원문 대조 자동 계산 | 하 |
| 포트폴리오 청킹 구현 | 현재 32k 토큰 초과 시 절단 + 경고만 → 분할 요청 후 결과 병합 | 중 |
