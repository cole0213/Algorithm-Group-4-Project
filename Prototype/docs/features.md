## 포트폴리오 업로드 & 파싱

- **단일 파일 업로드** — PDF · MD · TXT 파일 선택 또는 드래그 & 드롭
- **폴더 일괄 업로드** — 폴더 내 모든 파일을 한 번에 업로드
- **텍스트 붙여넣기** — 원문 텍스트를 직접 입력하거나 Ctrl+V로 붙여넣기
- **Solar LLM 자동 파싱** — 원문을 Upstage Solar API로 분석해 공통 스키마(이름·경력·학력·자기소개·기술·프로젝트·수상·링크)로 변환
- **업로드 진행 단계 표시** — 파일 읽는 중 → LLM 파싱 중 → 저장 중 → 완료 순서로 단계별 피드백
- **Solar 파싱 디버그 정보** — 파싱 완료 후 소요 시간·입력 토큰 수·출력 토큰 수 표시
- **이름 중복 감지** — 동일 이름의 지원자가 이미 존재할 경우 동명이인 여부 확인 후 추가
- **내용 중복 감지** — Rabin-Karp 유사도 비교로 원문이 유사한 포트폴리오를 감지하고 유사도 % 표시 후 강제 추가 또는 취소 선택
- **32k 토큰 초과 처리** — Solar 컨텍스트 한계 초과 시 분할 파싱 + 패널에 절단 경고 배너 표시
- **폴백 파싱** — Solar API 실패 시 기본 텍스트 파서로 자동 전환

## 지원자 목록 (사이드바)

- **지원자 수 표시** — 필터 적용 시 "N명 / 전체 M명" 형태로 표시
- **이름 빠른 검색** — 입력과 동시에 실시간으로 목록 필터링
- **이름 더블클릭 편집** — 사이드바에서 지원자 이름을 직접 수정
- **북마크** — ☆/★ 토글로 즐겨찾기 지정, 북마크된 지원자는 목록 최상단에 고정
- **심사 마킹** — 지원자별 통과 / 보류 / 탈락 드롭다운으로 상태 지정 및 색상 구분
- **매칭률 배지** — 매칭 점수를 색상으로 구분 (70%+ 녹색 / 40~69% 주황 / ~39% 빨간)
- **순위 번호** — 현재 정렬 순서에 따른 #N 순위 표시
- **조건 필터 패널** — ⚙ 버튼으로 열리는 필터 패널
  - 최소 경력 연수 (N년 이상)
  - 스킬 키워드 포함 여부
  - 등록일 범위 (시작일~종료일)
  - 필터 초기화 버튼
- **분석 중 스켈레톤 로딩** — 전체 재분석 실행 중 스켈레톤 카드 애니메이션 표시
- **지원자 삭제** — 목록에서 개별 삭제

## 포트폴리오 뷰어 (패널)

### 패널 기본 구조

- **최대 4개 동시 표시** — 사이드바에서 클릭 시 우측에 패널이 순서대로 나열 (초과 시 가장 오래된 패널 자동 닫힘)
- **패널 악센트 색상** — 패널 순서에 따라 고유 색상으로 구분
- **Solar 파싱 라벨** — Solar LLM으로 파싱된 포트폴리오에 "Solar" 라벨 표시
- **레거시 요약 배지** — 현재 채용 설정 이전 버전의 요약이 있을 경우 "레거시 요약" 경고 배지 표시
- **검색 필터 경고** — 현재 검색 결과에 포함되지 않는 지원자가 열려 있을 때 경고 표시
- **절단 경고 배너** — 원문이 토큰 한계를 초과해 일부만 처리된 경우 상단 경고 표시

### 섹션 구성

- **기본 정보** — 경력 연수, 학력, 이메일, GitHub, 등록일
- **기술 스택** — 스킬 배지 목록, 필요 스펙 매칭 여부 노란색 하이라이트, 5개 초과 시 "+N개 더보기" 접기/펼치기
- **자기소개** — Markdown 렌더링 (GFM 표·체크박스·취소선, 단일 줄바꿈 지원)
- **타임라인** — 수평 프로젝트 기간 시각화 (별도 목차 참고)
- **프로젝트** — 프로젝트명·기간·역할·기술·설명 목록
- **수상 및 활동** — 수상 내역 목록
- **중요 링크 버튼 바** — GitHub, Notion, LinkedIn, 블로그, YouTube, Figma, 포트폴리오 아이콘 자동 인식, 클릭 시 새 탭 열기
- **사용자 정의 섹션** — 채용 설정에서 정의한 추가 섹션 (Solar 재분석 시 내용 추출, 최대 6개)
- **섹션 아코디언** — 각 섹션 헤더 클릭으로 접기/펼치기
- **섹션 표시 제어** — 채용 설정의 visibleSections 기준으로 지정 섹션만 표시 가능

### 패널 내 검색 (intra)

- 패널 상단 검색 바에서 이 포트폴리오 내 키워드 검색 (300ms 디바운스)
- BST 기반 백엔드 검색과 화면 텍스트 기반 카운트 병행
- "N/M" 형태로 일치 개수 및 현재 위치 표시
- ▲ / ▼ 버튼으로 이전/다음 결과로 스크롤 이동
- 검색어 하이라이트 (파란 계열, 현재 포커스는 진하게)

### 패널 액션

- **전체화면 모드** — ⊞ 버튼으로 패널 전체화면 확장, ESC로 해제
- **유사 문장 숨기기 토글** — 패널별 독립 토글 (전역 설정과 별개)
- **Solar AI 재분석** — 확인 후 해당 포트폴리오를 Solar로 재파싱 (기존 결과 덮어쓰기)
- **채용 기준 요약** — Solar가 현재 채용 설정 기준으로 포트폴리오 요약 생성, 재요약 가능
- **원본 보기 모달** — 파싱 전 원본 텍스트를 "원본" / "마크다운 렌더링" 두 가지 뷰로 확인
- **메모** — 지원자별 자유 메모 입력, 400ms 디바운스로 localStorage 자동 저장
- **스크롤 위치 저장** — 패널을 닫았다 다시 열어도 이전 스크롤 위치 복원

### 텍스트 하이라이트 우선순위

유사 문장 하이라이트 → 전역 검색어 하이라이트 → intra 검색어 하이라이트 순서로 중첩 적용

## 채용 설정 & 점수 산출

### 채용 설정 모달 (JobConfigModal)

- **AI 자동 추출** — 채용 공고 텍스트를 입력하면 Solar LLM이 아래 모든 설정값을 자동으로 채워줌
- **필요 스펙 입력** — 쉼표로 구분된 기술 스택 목록 직접 입력
- **매칭 점수 가중치 슬라이더** — 기술 매칭 / 경력 / 프로젝트 세 항목을 슬라이더 + 숫자 입력으로 조절, 합계가 100이 아니어도 적용 시 자동 정규화
- **추가 섹션 정의** — 기본 7개 섹션 외 사용자 정의 섹션 추가 (최대 6개), Solar 재분석으로 내용 자동 추출
- **필터 조건**
  - 최소 경력 연수
  - 학력 키워드 (예: "대학교, 학사")
  - 직군 (전체 / 프론트엔드 / 백엔드 / 데이터·AI)
- **적용 + 전체 재분석** — 설정 저장 후 모든 지원자 포트폴리오를 즉시 재분석

### 점수 산출 & 표시

- 해시 테이블로 필요 스펙과 지원자 스킬을 O(1) 매칭
- LCS 알고리즘으로 0~100% 매칭 점수 산출
- 가중치 조합으로 최종 점수 계산
- 필요 스펙 일치 스킬 배지 노란 하이라이트 (`#FFD43B`)
- 매칭률 색상: 70%+ 녹색 / 40~69% 주황 / ~39% 빨간

## 검색

- **전역 검색 (cross)** — 이름·기술·키워드로 모든 포트폴리오에서 해당하는 지원자 목록 반환 (BST 기반), 300ms 디바운스
- **검색 히스토리** — 최근 8개 검색어를 localStorage에 저장, 드롭다운으로 빠른 재검색, 히스토리 전체 지우기 지원
- **별칭 통합 검색** — `py`, `파이선`, `파이썬` 입력 시 모두 Python으로 통합 검색 (Alias 해시맵 + Edit Distance)
- **패널 내 검색 (intra)** — 현재 열린 패널 내부에서 키워드 위치 탐색 (BST 기반, 이전/다음 네비게이션)
- **검색어 하이라이트** — 전역 검색어와 패널 내 검색어를 서로 다른 스타일로 동시 표시
- **정렬** — 매칭률 높은 순 / 경력 많은 순 / 이름 순

## 유사 문장 검출

- Rabin-Karp 롤링 해시 + LCS 검증으로 포트폴리오 간 유사 구간 자동 검출
- **6개 색상 그룹**으로 어느 구간끼리 유사한지 시각적으로 구분
- **표기 팔레트 3가지**
  - 흐리게 보기 (기본) — 유사 문장을 회색으로 흐리게 처리
  - 단일 색상 — 모든 유사 문장을 동일 색상으로 강조
  - 컬러풀 — 그룹별 다른 색상으로 강조
- **감지 범위 전환** — 저장된 포트폴리오 전체 / 현재 열린 패널 간만 선택
- **수동 재검출** — 설정 변경 후 즉시 재실행 버튼
- **유사 문장 흐리게 (전역)** — 설정 드로어에서 전체 패널에 일괄 적용
- **패널별 독립 숨기기** — 각 패널 헤더의 👁/🙈 버튼으로 해당 패널만 토글

## 비교 분석 (Diff)

- 열린 패널이 2~4개일 때 상단 툴바에 "⇄ N명 비교" 버튼 노출
- **테이블 비교** — 항목(경력·기술·프로젝트 수 등) × 지원자 그리드, 우세한 항목에 ✓ 표시
- **집중 비교 (2명)** — 두 포트폴리오를 항목별로 좌우 나란히 비교
- **AI 코멘트** — 집중 비교에서 각 항목별 "A 우세 / B 우세 / 동등" 코멘트 표시, 숨기기 토글 제공
- **Solar AI 분석 / 로컬 비교 배지** — Solar 연동 시 "Solar AI 분석", 실패 시 "로컬 비교" 표시
- ESC 또는 배경 클릭으로 닫기

## 시각화

### 타임라인 (Timeline)

- 프로젝트 기간을 수평 타임라인으로 시각화
- 6가지 날짜 형식 파싱: `2023.06-2023.12`, `Jun 2023 - Dec 2023`, `2022~현재` 등
- 겹치는 기간은 별도 트랙으로 분리하여 겹침 없이 표시
- 각 이벤트 바에 프로젝트명·역할·기술·기간 툴팁

### 스킬 매트릭스 (SkillMatrix)

- 모든 지원자 × 모든 스킬을 그리드로 표시
- 보유(✓) / 미보유(·) 직관적 구분
- 스킬별 보유 인원 수 / 전체 비율 막대 표시
- 보유 인원 빈도 내림차순으로 스킬 정렬
- 상단 바 아이콘으로 모달 열기, CSV 내보내기 지원

## 동기화 스크롤

- 포트폴리오 영역 상단 툴바의 토글 스위치로 ON/OFF
- ON 상태에서 한 패널을 스크롤하면 나머지 패널이 비율에 맞춰 동시에 스크롤
- 각 패널의 scrollHeight 비율을 계산해 동기화 (길이가 다른 패널도 대응)

## 블라인드 심사 모드

- 설정에서 활성화 시 사이드바 목록과 패널 헤더의 지원자 이름을 "지원자 #N" 형태 별칭으로 대체
- 무의식적 이름 편향 없이 내용만으로 평가 가능

## 세션 관리

- **JSON 내보내기** — 현재 세션의 모든 포트폴리오 데이터를 JSON 파일로 다운로드
- **JSON 가져오기**
  - 덮어쓰기: 중복 ID는 파일 내용으로 교체, 나머지는 유지
  - 전체 초기화: 기존 포트폴리오를 모두 삭제하고 파일로 교체
- **자동 저장** — 백엔드 `session.json` + 브라우저 localStorage에 이중으로 유지
- **메모 저장** — 지원자별 메모를 localStorage에 자동 저장
- **북마크·마킹 저장** — localStorage에 지속 저장 (페이지 새로고침 후에도 유지)
- **검색 히스토리 저장** — 최근 8개 검색어를 localStorage에 저장

## 설정 (Settings Drawer)

설정 버튼으로 우측에서 밀려 들어오는 드로어로 관리

### 토글 스위치 (8가지)

- 스킬 하이라이트 — 필요 스펙과 일치하는 기술 배지 노란 강조
- 유사 문장 표시 — Rabin-Karp 검출 결과 색상 강조
- 유사 문장 흐리게 — 강조 대신 opacity 0.3으로 흐리게 처리
- 동기화 스크롤 — 패널 동기화 스크롤 ON/OFF
- 원본 보기 버튼 — 패널 상단에 "원본 보기 →" 버튼 표시 여부
- 별칭 통합 검색 — 동의어 기반 검색 확장 ON/OFF
- 블라인드 심사 모드 — 이름 가리기 ON/OFF
- 다크 모드 — 어두운 테마 전환

### 가중치 편집

- 스킬 일치 / 경력 / 프로젝트 수 세 항목 슬라이더 조절
- "수정" 버튼 클릭 후 숫자 입력으로 정밀 조절, "적용" 시 자동 정규화
- 합계 실시간 표시

### 유사 문장 감지 설정

- 감지 범위: 전체 포트폴리오 / 열린 패널만
- 표기 팔레트: 흐리게 보기 / 단일 색상 / 컬러풀
- 수동 재검출 버튼

## 기타

- **홈 페이지** — 프로젝트 소개 랜딩 페이지, 분석 화면에서 "← 홈" 버튼으로 이동
